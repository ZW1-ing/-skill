# 老板画饼模拟器

一个帮助你练习应对老板画饼话术的 Claude Code 技能。

## 功能特点

- **10+ 种经典画饼场景**：涵盖晋升承诺、股票期权、加班无补偿、情怀绑架等
- **真实角色扮演**：Agent 扮演老板，使用真实画饼话术
- **互动式演练**：根据你的回应进行追问和施压
- **详细复盘分析**：提供优点、不足和改进建议
- **实用应对策略**：多种话术模板供参考

## 安装方法

### 方法一：自动安装（推荐）

技能已经自动安装到 Claude Code 的技能目录：

```bash
~/.claude/skills/boss-painting-cakes/
```

### 方法二：手动安装

如果需要手动安装，请按照以下步骤：

1. 将 `boss-painting-cakes` 文件夹复制到 `~/.claude/skills/` 目录
2. 在 `~/.claude/settings.json` 中添加技能配置：

```json
{
  "skills": [
    {
      "name": "boss-painting-cakes",
      "path": "~/.claude/skills/boss-painting-cakes/skills/boss-painting-cakes/SKILL.md",
      "enabled": true
    }
  ]
}
```

3. 重启 Claude Code 以加载新技能

## 使用方法

### 基本用法

在 Claude Code 中直接输入以下命令：

```bash
# 随机画饼场景演练
/boss-painting-cakes

# 指定场景演练
/boss-painting-cakes 升职加薪
/boss-painting-cakes 股票期权
/boss-painting-cakes 加班无补偿

# 根据具体情境演练
/boss-painting-cakes 我刚拒绝加班
/boss-painting-cakes 老板说要给我升职
```

## 演练流程

### 第一步：场景初始化
- Agent 询问你当前的工作背景
- 你描述具体的画饼场景或选择预设场景
- Agent 确认演练目标和重点

### 第二步：角色扮演
- Agent 扮演老板，使用经典画饼话术
- 语气自然、真实，模拟真实职场场景
- 根据你的回应进行追问和施压

### 第三步：你来应对
- 尝试用学到的策略回应老板的画饼
- Agent 会根据回应质量给予即时反馈
- 提供改进建议和更优的回应方式

### 第四步：复盘总结
- 分析你回应的优点和不足
- 提供多种应对策略供参考
- 将演练结果写入文档

## 演练示例

```
用户：/boss-painting-cakes 我想练习应对老板画饼说要给我升职

Agent（扮演老板）：
小李啊，来来来，坐。最近项目做得不错，我很看好你。
公司现在发展很快，明年肯定要扩大团队，到时候需要更多的负责人。
你再努力一年，组长的位置肯定是你的。

用户：谢谢领导认可，但我想了解一下具体的晋升标准是什么？

Agent（扮演老板）：
这个嘛...主要还是看综合表现。你放心，我心里有数。

用户：能不能把这个标准明确一下？比如KPI达到什么程度，或者完成哪些项目？

Agent（扮演老板）：
嗯...你这样问就显得太功利了。年轻人不要太计较，要看长远。

用户：我理解要看长远，但明确的标准对双方都好。
我可以有个努力的方向，您也可以更客观地评估。

Agent（复盘）：
很好！你的回应有几个亮点：
1. 先表达感谢，保持礼貌
2. 追问具体标准，要求明确化
3. 在被质疑后依然坚持，但语气委婉
4. 把"功利"转化为"对双方有利"

改进建议：可以在最后补充一句，
比如"如果今年能达到XX目标，是否可以提前考虑晋升？"
```

## 包含的场景

1. **晋升承诺** - "明年经理位置就是你的"

## 应对原则

### 黄金法则

1. **保持礼貌但坚定**：不要情绪化，但也不要轻易妥协
2. **要求具体化**：把模糊的承诺转化为明确的指标和时间表
3. **书面确认**：重要承诺尽量要求邮件或书面确认
4. **设定底线**：明确自己的底线，不要被情怀绑架
5. **留有后路**：画饼可以听，但不要把所有希望都寄托于此

### 常用话术模板

| 场景 | 回应模板 |
|------|----------|
| 模糊承诺 | "谢谢领导认可，能否具体说一下评估标准？" |
| 时间拖延 | "我理解需要时间，能否先定一个短期目标？" |
| 情怀绑架 | "理想很重要，但合理的回报也不矛盾。" |
| 对比他人 | "我只关注我在这里的价值和回报。" |
| 未来画饼 | "未来是美好的，但目前的保障也很重要。" |
